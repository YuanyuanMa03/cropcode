# 工作台与设计预览

新工作台已经接入现有 `SessionManager`。Web 和桌面薄壳使用同一个本机服务，与终端共享会话格式、工具、权限和模型配置。

## 启动真实工作台

在仓库根目录使用 Node 22.12+（Node 22 系列）或受 Vite 支持的更新版本：

```sh
npm install
npm run build
node packages/cli/dist/cli.js web --port 8787
```

打开终端打印的完整地址（含一次连接所需的 token）。服务只监听 `127.0.0.1`；鉴权后地址中的 token 会被清除，刷新通过 HttpOnly cookie 恢复连接。请勿将完整地址分享给他人。

新构建的桌面端加载同一工作台。已经安装的旧版应用需重新构建安装包才能包含这些变化。终端 Ink 界面仍保留现有布局。

## 当前支持

- 单个本机项目的真实任务列表、搜索、新建和历史切换。服务重启后可从列表重新打开旧会话。
- 模型流式回复、可折叠的思考及工具文本、进程输出、停止生成。
- 显示具体命令与作用域，逐次允许或拒绝权限请求；刷新后仍可处理待确认请求。
- 计划模式与确认实施；内核提问通过输入框自由回答。
- `@` 查询真实项目文件；`/` 菜单复用终端的共享命令注册表。方向键选择，Tab/Enter 补全，Esc 关闭；Enter 发送，Shift+Enter 换行，输入法确认不发送。
- SSE 断线自动重连，完整快照替换状态，避免把重播内容重复追加。多标签页共享一个活动会话；服务端拒绝过期会话和权限请求。
- 按会话保存当前页面中的输入草稿、浅色/深色主题、窄屏导航。草稿不持久化，刷新会清空。

模型设置暂时通过侧栏的“模型设置与旧版工作台”打开 `/legacy`，也可在终端使用 `/login`。密钥只发送给本机服务，不随状态返回浏览器。旧界面提供返回新版入口。

输出采用纯文本安全渲染。界面显示最近 200 条消息，每条最多 24000 字符，完整历史仍由内核保存。当前没有交互式 Shell、真实文件差异面板或多项目切换；进程输出来自内核实际执行的工具。

## 独立设计预览

```sh
npm run dev:workbench
# 或
npm run build:workbench
npm run preview:workbench
```

在输出地址的 `/workbench/` 后添加 `?preview=1`，例如 `http://127.0.0.1:5173/workbench/?preview=1`。预览保持六个演示场景，使用隔离的演示数据，不执行真实任务。单独的 Vite 服务不提供会话 API；真实工作台请用上面的 CLI 服务启动。

## 实现边界

`apps/web` 是 Vite 入口，`packages/ui` 提供 React 组件、样式及浏览器会话适配。HTTP 命令和 SSE 状态沿用本机 Web 主机；所有会话与执行逻辑保留在 core。构建生成静态资产 manifest，服务端只加载登记的 JS/CSS 和固定入口文件，不开放任意文件服务，不放宽 CSP。

验证使用真实内核、文件落盘和历史重载；自动测试只替换模型响应，不请求真实供应商。真实供应商的可用性仍取决于本机配置和网络。
