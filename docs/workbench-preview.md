# 工作台设计预览

这是三端升级的 P0 设计预览，使用演示数据检查布局、主题和交互。它尚未连接会话内核，不会读取项目文件、保存供应商密钥、请求模型或执行终端命令。现有 `cropcode web`、终端和桌面安装包仍使用原有界面。

## 启动

在仓库根目录使用 Node 22.12+（Node 22 系列）或受 Vite 支持的更新版本：

```sh
npm install
npm run dev:workbench
```

访问输出的本机地址，通常为 `http://127.0.0.1:5173`。开发入口只监听本机。构建及预览：

```sh
npm run build:workbench
npm run preview:workbench
```

开发工具不随当前 CLI/桌面安装包发布。

## 体验范围

顶栏可以切换六个设计场景：项目首页、任务对话、等待授权、文件与变更、设置、终端界面；也可以查看载入、空白、连接错误的演示状态。重置按钮清空当前演示输入与授权状态。

- 项目和任务导航、搜索，以及按任务保留的草稿。
- 输入框的多行输入、演示文件/命令入口和演示回复。
- 一次性授权或拒绝，以及明确的结果反馈。
- 文件搜索、只读文件、代码差异和图表产物示例。
- 浅色/深色主题；只有主题偏好保存到浏览器，刷新后演示任务重置。
- 终端外观及输入反馈。它是浏览器中的终端设计样例，尚未修改真实 Ink 界面，也不是 Shell。
- 窄屏导航抽屉和文件面板；手机尺寸适配不代表支持跨设备连接。

`Cmd/Ctrl+K` 打开任务搜索，`Cmd/Ctrl+N` 新建演示任务。Enter 提交输入，Shift+Enter 换行；中文输入法确认候选词时不应提交。Escape 关闭导航与文件面板。

## 实现边界

`apps/web` 是 Vite 入口；`packages/ui` 提供 React 组件、CSS 语义设计变量和隔离的演示数据。原型使用 Radix Dialog 与图标。Tailwind、Zustand、协议及真实服务适配按后续阶段引入，不提前增加依赖。

本阶段没有把 ZCode 源码或品牌资源复制进项目。后续接入真实 core 时，将补齐项目/任务状态契约、断线恢复、资产 manifest、安装包验证，再替代原有 Web 界面。
