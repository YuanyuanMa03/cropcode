# CropCode 2.0 升级记录

目标是可实际使用的科研产品：桌面和终端共享一套内核。VSCode 插件退出交付范围。版本已统一为 2.0.0；本地构建不等于正式发行，以下按实际证据记录状态。

## 已实现

- 研究工作台：灰绿浅色与深色主题，项目、任务、文件、终端和变更；不显示引导、职业问卷、市场、套餐和远程工作区。
- 供应商中立：API 模板与自定义端点，不预置供应商实例；终端 `configure` 与桌面共用模型配置。
- 终端：交互 TUI、模型选择、单次任务、会话恢复；单次任务默认 build 模式，yolo 必须显式指定。
- 独立终端包直接装配 Agent、Node 和原生模块，不再使用 VSCode 插件构建产物。
- 停用产品账号、远程配置、遥测与自动更新；保留本机运行时、用户配置的模型、技能和 MCP。
- 修复桌面主进程类型错误、任务索引取消订阅与 Agent 关闭之间的竞态，以及设置通知的重复 IPC 监听。
- 版本脚本同步桌面与终端；许可证和第三方来源声明保留。

## 本机验收

验收环境为 macOS arm64、Node 24.14.0、Electron 41.0.3。测试数据和凭证副本位于隔离的本机目录，不进入仓库或安装包。

- 先前 `pnpm check`：共享模块、桌面主进程、CLI 和当时的 VSCode 类型检查、lint 与格式检查通过；继承代码仍有 lint 警告。现在门禁只覆盖交付的桌面和 CLI。
- `pnpm test:product`：8 项测试通过，覆盖产品出口、遥测、身份、默认市场/插件、远程场景及模型配置的持久化和凭证输入。
- `pnpm test:kernel`：实际构建的 Agent 使用本地模型夹具调用真实工具，读取 CSV、计算逐日积温并写文件。重读磁盘确认 14、16、12，总计 42 ℃·日，原始 CSV 不变。完成会话恢复及 plan 模式禁止写入检查。
- 实际终端 TUI 启动、显示 CropCode、读取模型配置并打开模型选择器。
- 先前曾在 VSCode 开发宿主中完成任务和工具验收；这项历史结果不属于现行交付范围。
- macOS DMG 校验通过，从镜像复制应用后独立启动成功，应用版本 2.0.0、标识 org.cropcode.desktop；重启后历史任务仍可见。权限拒绝后结果文件内容与修改时间不变。
- 先前 VSIX 曾在隔离目录通过安装检查；现已停止交付。独立终端归档补齐 OpenTUI 动态加载的原生 FFI 依赖；从全新解压目录以内置 Node 完成版本与渲染库初始化测试，本机 `cropcode` 命令实际启动 TUI，不依赖系统 Node。
- 先前三个产物附 SHA256SUMS；现行产品只保留桌面与终端。先前终端包和 VSIX 扫描未包含测试凭证。
- 桌面浅色/深色、窄窗口、研究入口预填、精简设置和自定义模型保存已通过实际窗口检查。
- 清理 6 项无源码引用的界面依赖后，重新构建的 macOS arm64 `app.asar` 为 278 MB，检查确认不含这些依赖；内置 Electron 以 Node 模式实际启动成功，`pnpm check`、`pnpm test:product` 与 `pnpm test:kernel` 通过。

本地模型夹具只替代模型网络响应，文件、权限、终端、会话和工具执行都使用真实实现。它不证明外部供应商可用，也不证明科学任务能自主正确完成。

## 2026-09-28 简单对比

同一台 macOS arm64、同一 `glm-5.3` 与同一三行 `weather.csv`（其中 2026-07-02 为负降雨量、2026-07-03 为缺测），从真实界面提交同一句读取任务。旧版是已安装的 1.1.0，升级版是本机打包的 2.0.0；每格只有一次样本。

| 界面    |     旧版 |    2.0.0 | 结果                           |
| ------- | -------: | -------: | ------------------------------ |
| CLI     | 30.36 秒 |  7.61 秒 | 两版都答对日期                 |
| Desktop | 约 94 秒 | 约 10 秒 | 两版都答对日期，均显示工具执行 |

桌面计时从发送到界面显示最终回答。旧版桌面显示 `bash` 和 `read` 工具，2.0.0 显示终端工具调用；旧版此轮显示 17,464 tokens。两版默认推理强度和上下文设置不同，且只跑一次，因此这些数字只描述本机体验，不足以把耗时差异归因于桌面界面或内核。CLI 的简单事实题另得 34.59/4.59 秒，失败恢复题 15.18/9.30 秒（旧版/2.0.0），结果均正确；旧版恢复题的具体工具序列没有核实。测试用临时项目凭证已删除。

更复杂的双任务代码修复与隐藏测试评分见 [2026-09-29 Agent 基准测试](agent-benchmark-2026-09-29.md)。
