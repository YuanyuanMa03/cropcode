# CropCode for VSCode

CropCode 的 VSCode companion，与 CLI 共享 `.cropcode/settings.json`、会话和核心工具。

模型供应商可先在 CLI 通过 `/login` 配置，也可直接编辑配置文件。当前编辑器模型菜单保留 DeepSeek 预设，其他模型使用配置文件选择。

从 [GitHub Releases](https://github.com/YuanyuanMa03/cropcode/releases) 获取 VSIX，通过 VSCode 的“从 VSIX 安装”安装。源码构建使用 `npm run build:vscode`。
