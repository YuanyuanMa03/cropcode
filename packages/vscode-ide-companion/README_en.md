# CropCode for VSCode

The VSCode companion shares `.cropcode/settings.json`, sessions and core tools with the CLI. Configure providers using the CLI `/login` wizard or settings files. The editor model menu retains DeepSeek presets; other models can be selected in settings.

Build with `npm run build:vscode`, then use VSCode's Install from VSIX action. Project and license details: https://github.com/YuanyuanMa03/cropcode.
